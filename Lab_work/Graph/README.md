## 学习顺序建议

### 第一阶段：图的存储
1. **理解图的两种存储方式**
   - **邻接矩阵**：适合稠密图，查询快 O(1)
   - **邻接表**：适合稀疏图，节省空间

### 第二阶段：图的遍历
2. **graph_traversal_dfs.c** - 深度优先遍历
   - 递归实现
   - 应用：路径查找、连通性判断
   - **重点**：理解回溯思想

3. **graph_traversal_bfs.c** - 广度优先遍历
   - 队列实现
   - 应用：最短路径（无权图）、层级遍历
   - **重点**：理解队列在图中的应用

### 第三阶段：最小生成树
4. **graph_mst_prim.c** - Prim算法
   - 顶点驱动，适合稠密图
   - **重点**：理解贪心策略

5. **graph_mst_kruskal.c** - Kruskal算法
   - 边驱动，适合稀疏图
   - **重点**：理解并查集

## 核心概念

### 1. 邻接矩阵 vs 邻接表

| 特性 | 邻接矩阵 | 邻接表 |
|------|---------|-------|
| 空间复杂度 | O(V²) | O(V+E) |
| 查询边是否存在 | O(1) | O(degree) |
| 遍历所有边 | O(V²) | O(V+E) |
| 适用场景 | 稠密图 | 稀疏图 |

### 2. DFS vs BFS

| 特性 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈（递归） | 队列 |
| 空间复杂度 | O(h)深度 | O(w)宽度 |
| 应用场景 | 路径查找、连通性 | 最短路径（无权） |
| 遍历顺序 | 深度优先 | 层级遍历 |

### 3. Prim vs Kruskal

| 特性 | Prim | Kruskal |
|------|------|---------|
| 算法思路 | 顶点逐步加入 | 边逐步加入 |
| 数据结构 | 优先队列 | 并查集 |
| 时间复杂度 | O(V²) 或 O(E log V) | O(E log E) |
| 适用场景 | 稠密图 | 稀疏图 |

## 算法详解

### DFS深度优先遍历
**算法步骤**：
1. 从起点开始访问并标记
2. 递归访问所有未访问的邻接顶点
3. 回溯到上一层，继续访问其他邻接顶点

**应用场景**：
- 判断图的连通性
- 检测图中是否有环
- 拓扑排序（有向无环图）

### BFS广度优先遍历
**算法步骤**：
1. 将起点入队并标记
2. 队首出队，访问其所有未访问的邻接顶点
3. 将这些邻接顶点入队
4. 重复步骤2-3直到队列为空

**应用场景**：
- 无权图的最短路径
- 层级遍历
- 社交网络的"朋友圈"分析

### Prim算法（最小生成树）
**算法步骤**：
1. 从任意顶点开始，加入生成树
2. 选择一条权重最小的边，连接生成树和外部顶点
3. 将该顶点加入生成树
4. 重复步骤2-3直到所有顶点都加入

**特点**：
- 贪心算法
- 适合稠密图
- 每次选择局部最优

### Kruskal算法（最小生成树）
**算法步骤**：
1. 将所有边按权重从小到大排序
2. 依次选择边，若该边不形成环则加入生成树
3. 重复步骤2直到选择了V-1条边

**特点**：
- 贪心算法 + 并查集
- 适合稀疏图
- 需要排序所有边

## 常见问题

### Q1: 什么是最小生成树？
**A**: 在一个连通加权无向图中，选择V-1条边连接所有顶点，使得总权重最小。

**性质**：
- 有V-1条边（V为顶点数）
- 无环
- 连通
- 权重和最小

### Q2: 如何判断图中是否有环？
**A**:
- **无向图**：DFS过程中，若遇到已访问且不是父节点的顶点，则有环
- **有向图**：DFS过程中，若遇到"正在访问"状态的顶点，则有环

### Q3: 什么情况下不存在最小生成树？
**A**: 图不连通时，不存在生成树。可以求**最小生成森林**（每个连通分量的生成树）。

### Q4: 并查集在Kruskal中的作用？
**A**: 快速判断两个顶点是否在同一连通分量中，避免形成环。

## 进阶话题

### 1. 最短路径算法
- **Dijkstra算法**：单源最短路径（非负权重）
- **Bellman-Ford算法**：单源最短路径（允许负权重）
- **Floyd-Warshall算法**：所有顶点对最短路径

### 2. 拓扑排序
- 适用于有向无环图（DAG）
- 应用：任务调度、课程安排

### 3. 关键路径
- AOE网（Activity On Edge）
- 应用：工程管理
